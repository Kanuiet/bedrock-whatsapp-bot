# bedrock-whatsapp-bot

A minecraft-whatsapp bot using the [Baileys](https://github.com/WhiskeySockets/Baileys) and [bedrock-protocol](https://github.com/PrismarineJS/bedrock-protocol) libraries.

## Installation

``` shell
# Clone the repository
git clone https://github.com/Kanuiet/bedrock-whatsapp-bot/
cd bedrock-whatsapp-bot

# Install dependency
npm install

# Start the bot
node .
```
